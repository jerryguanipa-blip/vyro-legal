## Deliberately NOT on the site
- Ratings, download counts, user counts, testimonials: none exist. Prices appear only in the plans block, marked as planned for launch; the final price is whatever Google Play shows.
- Any statement that WhatsApp's compression is avoided: it is not. The site says the opposite.
- Comparisons with other apps.
- Real app screenshots: the before/after block is an illustrative vector mock-up (labelled as such). Replace it with real captures when available.
